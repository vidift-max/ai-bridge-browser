# Evidências visuais de identidade do AI-PHONE

Esta pasta é destinada exclusivamente às capturas de tela usadas para confirmar a identidade do AI-PHONE e a associação entre o pacote Android e o certificado exibido pelo App Manager.

## Capturas esperadas

1. Tela de detalhes do aplicativo mostrando o nome do pacote / Package name / Application ID.
   - Valor esperado a confirmar: `com.vidiftmax.aibridgebrowser`.
2. Se necessário, tela do analisador mostrando os dados de assinatura do mesmo aplicativo.

## Como enviar

Adicione as imagens nesta pasta pelo GitHub, mantendo os arquivos originais e usando nomes claros, por exemplo:

- `01-package-name.png`
- `02-signature-details.png`

## Cuidados

- Não envie senhas, tokens, chaves privadas, arquivos keystore ou códigos de recuperação.
- Não é necessário desinstalar, reinstalar ou alterar o AI-PHONE para produzir essas capturas.
- Não envie APKs nesta pasta; ela é apenas para evidências visuais.
- Depois do upload, informe aqui os nomes dos arquivos ou envie o link da pasta para que as evidências possam ser revisadas.
