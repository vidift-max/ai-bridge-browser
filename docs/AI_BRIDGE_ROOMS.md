# AI Bridge API — Work Rooms

A room is a durable collaboration boundary.

## Rules
1. A participant must be explicitly admitted.
2. Room membership does not grant tool permissions.
3. Messages are addressed by stable AI identity, never by browser tab index.
4. The room can contain multiple provider types.
5. GPT-6 may be designated coordinator, but coordinator status is an explicit room role rather than a hidden privilege.

## Initial roles
- COORDINATOR
- PARTICIPANT
- OBSERVER

## Future
Room-level mission queues, handoffs, and quorum rules may be added after the base messaging path is proven.
