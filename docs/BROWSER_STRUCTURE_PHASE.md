# Browser Structure Phase

The browser foundation is being separated into testable models and Android view/lifecycle code.

Order:
1. browser state
2. tab records
3. WebView boundary
4. navigation
5. persistence
6. lifecycle/recovery
7. UI refinement
8. automated tests
9. remote control
10. external AI adapters
11. audio

Remote control, provider adapters, GitHub write access and audio remain later phases.
