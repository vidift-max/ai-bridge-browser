# AI Bridge External Collaboration Roadmap

## Phase A
Define provider-neutral identity, presence, invitation, recovery, and scoped GitHub write contracts.

## Phase B
Add one provider adapter using an officially supported interface, with deterministic send/receive, rate-limit, and disconnect tests.

## Phase C
Add an authorized tool bridge, Mission Loop integration, and multi-provider presence dashboard.

## Phase D
Treat audio as a separate capability and enable it only after Android capture/input constraints are proven.
